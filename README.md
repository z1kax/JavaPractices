# Практические работы по курсу "Информационные системы в бизнесе"

**Автор:** @z1kax

**Семестр:** 3

## О проекте
Репозиторий содержит решения практических работ по языку Java. Все задания выполнены в рамках курса.

Все ключевые проектные решения и обоснования описаны в файле [DECISIONS.md](./DECISIONS.md).

## Структура репозитория
- `src/ru/edu/pr01` - Проектирование ИС (UML) и главный класс для тестирования
- `src/ru/edu/pr03` - Базовые типы данных и арифметика
- `src/ru/edu/pr05` - Строки, массивы и циклы (Табель)
- `src/ru/edu/pr06` - Логические операторы и маршрутизация заявок
- `src/ru/edu/pr07` - ООП: Корпоративный заказ оборудования
- `src/ru/edu/pr08` - Инкапсуляция и управление состоянием (Командировки)

## Как запустить
Для запуска тестов всех практик используйте скрипты в корне проекта:
- **Windows:** запустите файл `run_selfcheck.bat`
- **Mac/Linux:** выполните `bash run_selfcheck.sh`
